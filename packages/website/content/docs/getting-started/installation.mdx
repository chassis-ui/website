## Introduction

Chassis is installed one package at a time. This guide helps you choose the package to start with and gives its first command. The documentation of that package takes it from there.

There are two ways in. A design system of your own starts with Tokens, Figma, Assets or Icons. A web project that uses Chassis as it is starts with CSS.

## Prerequisites

- [Node.js](https://nodejs.org/) 22.12 or later, for every package that is installed from npm.
- A [Figma](https://www.figma.com/) account that can publish libraries, to start with Chassis Figma.

## Start with the tokens

Start here when you own the design decisions: color, type, spacing and motion for each brand. Run the `init` command of Chassis Tokens:

```bash
npx @chassis-ui/tokens init acme-tokens
```

The command writes a repository of tokens into the folder `acme-tokens`. The [Quick Start Guide](/tokens/docs/getting-started/quick-start/) of Chassis Tokens changes a token, builds it and uses it in a project.

## Start with Figma

Start here when you design screens. Duplicate the libraries from [Figma Community](https://www.figma.com/@[[config:figmaHandle]]) and publish them to your team. [Library Setup](/figma/docs/getting-started/library-setup/) of Chassis Figma has the steps.

## Start with the assets

Start here when you own the files of a brand: its logos, images and fonts. Run the `init` command of Chassis Assets:

```bash
npx @chassis-ui/assets init acme-assets
```

The command writes a repository of assets into the folder `acme-assets`. The [Quick Start](/assets/docs/getting-started/quick-start/) of Chassis Assets runs its first build.

## Start with the icons

Start here when you have a set of SVG icons. Run the `init` command of Chassis Icons:

```bash
npx @chassis-ui/icons init acme-icons
```

The command writes a repository of icons into the folder `acme-icons`. The [Quick Start](/icons/docs/getting-started/quick-start/) of Chassis Icons builds the set and releases it.

## Start with a web project

Start here when you build a website or a web app. Install Chassis CSS, and the icons of Chassis if you want them. In your project:

```bash
npm install @chassis-ui/css @chassis-ui/website-icons
```

The compiled CSS has the styling of Chassis. To style it with tokens of your own, build them with Chassis Tokens and compile Chassis CSS from its Sass source.

- [Installation](/css/docs/getting-started/installation/) of Chassis CSS covers the compiled CSS, the Sass source and the JavaScript.
- [Chassis CSS](/icons/docs/use-in-project/chassis-css/) of Chassis Icons covers the icons in a page that uses Chassis CSS.
- [Introduction](/react/docs/getting-started/introduction/) of Chassis React covers the React components, which use the stylesheet of Chassis CSS.

Chassis is an open-source design system toolkit for products with several brands and platforms. It is made of separate projects, each in its own repository and each under the MIT license. The design tokens come first, and the other projects build on them.

## The projects

### Chassis Tokens

Chassis Tokens builds a repository of design tokens in [Tokens Studio](https://tokens.studio) format, synced with Figma. A [Style Dictionary](https://styledictionary.com) build turns them into SCSS variables for the web, Swift constants for iOS and resources for Android. The builder is published to npm as `@chassis-ui/tokens`, with the `chassis-tokens` command. The tokens of Chassis are one such repository, [chassis-ui/website-tokens](https://github.com/chassis-ui/website-tokens), and its output is published to npm as `@chassis-ui/website-tokens`. iOS apps can also install it as a Swift package, and Android apps as a library from the GitHub releases. To use tokens of your own, start a repository with `chassis-tokens init` and build your own brands.

### Chassis CSS

Chassis CSS is a CSS framework built on the tokens. It has components, utility classes, context classes that change the color palette of an element (`primary`, `success`, `danger` and others), and JavaScript plugins, typed with TypeScript, for the interactive components. It ships compiled CSS, the Sass source and an entry for Tailwind CSS v4. It is published to npm as `@chassis-ui/css`. Chassis CSS is derived from [Bootstrap](https://getbootstrap.com/).

### Chassis Icons

Chassis Icons builds a repository of SVG files into an icon library: optimized SVGs, an SVG sprite, an icon font with its CSS and SCSS, and, when a set asks for them, an asset catalog for iOS and resources for Android. The builder is published to npm as `@chassis-ui/icons`, with the `chassis-icons` command. The icons of Chassis are one such repository, [chassis-ui/website-icons](https://github.com/chassis-ui/website-icons), and its output is published to npm as `@chassis-ui/website-icons`. To make an icon library of your own, start a repository with `chassis-icons init` and save your SVG files into it.

### Chassis Assets

Chassis Assets copies, renames and distributes design assets, such as fonts, images and illustrations, for each brand, app and platform: web, iOS and Android. It is published to npm as `@chassis-ui/assets`, and builds a repository of assets of your own. The assets of the Chassis sites and apps are in `chassis-ui/website-assets`, which releases an archive per platform, app and brand.

### Chassis Figma

Chassis Figma documents the Chassis component library in Figma: how the components map to design tokens and to code. It is documentation only, and there is nothing to install.

### Chassis React

Chassis React is a library of React components, written in TypeScript, built on [React Aria](https://react-spectrum.adobe.com/react-aria/) and styled with Chassis CSS. It is published to npm as `@chassis-ui/react` and needs React and React DOM 18 or later.

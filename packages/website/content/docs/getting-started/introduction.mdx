## Introduction

Chassis is an open-source toolkit for teams with more than one brand, app or platform. A design decision is made in one place, as a design token, and reaches every brand, every app and every platform from there.

Chassis is made of packages. Each one has its own repository, its own version and its own documentation, and each is under the MIT license. A team adopts one package, or all of them.

## How the packages connect

The design tokens come first, and the other packages read them:

- **Tokens** holds the decisions: color, type, spacing and motion, for each brand, theme and app.
- **Figma** is bound to the tokens as Variables, so a design uses the same names as the code.
- **CSS** is built on the tokens, and **React** is styled by CSS.
- **Assets** and **Icons** build the files that tokens cannot hold: fonts, images and icons.

A brand has the same name in every package. A site or an app that builds with that name gets the tokens, the fonts, the images and the icons of the brand.

## Builders and their sets

Tokens, Assets and Icons are builders. A builder holds a build and no files of a brand: its `init` command writes a repository for your team, and its build turns the files of that repository into the output of each platform.

Chassis has a repository of its own for each builder, which the Chassis sites and the Figma library use. A team with a design system of its own uses its own repositories in their place:

<CxTable>
| Set | Repository | npm package |
| --- | --- | --- |
| The tokens of Chassis | [chassis-ui/website-tokens](https://github.com/chassis-ui/website-tokens) | `@chassis-ui/website-tokens` |
| The icons of Chassis | [chassis-ui/website-icons](https://github.com/chassis-ui/website-icons) | `@chassis-ui/website-icons` |
| The assets of Chassis | [chassis-ui/website-assets](https://github.com/chassis-ui/website-assets) | None. It releases archives |
</CxTable>

## The packages

Each package is described by what it does. Its documentation holds the rest.

<CxTable>
| Package | What it is | Repository | npm package |
| --- | --- | --- | --- |
| [Chassis Tokens](/tokens/) | The builder of design tokens. It turns a repository of [Tokens Studio](https://tokens.studio) files, synced with Figma, into SCSS for the web, Swift for iOS and resources for Android | [chassis-ui/tokens](https://github.com/chassis-ui/tokens) | `@chassis-ui/tokens` |
| [Chassis Figma](/figma/) | The component library in Figma, published on Figma Community. A team duplicates the libraries and publishes them to its own workspace | [chassis-ui/figma](https://github.com/chassis-ui/figma) | None |
| [Chassis CSS](/css/) | A CSS framework built on the tokens: components, utility classes and JavaScript plugins for the interactive components. Derived from [Bootstrap](https://getbootstrap.com/) | [chassis-ui/css](https://github.com/chassis-ui/css) | `@chassis-ui/css` |
| [Chassis React](/react/) | React components built on [React Aria](https://react-spectrum.adobe.com/react-aria/) and styled with Chassis CSS | [chassis-ui/react](https://github.com/chassis-ui/react) | `@chassis-ui/react` |
| [Chassis Assets](/assets/) | The builder of design files. It copies the fonts and images of each brand and app into the names, formats and folders of each platform | [chassis-ui/assets](https://github.com/chassis-ui/assets) | `@chassis-ui/assets` |
| [Chassis Icons](/icons/) | The builder of icon sets. It turns a repository of SVG files into an icon font, a sprite, optimized SVG files and the files of apps | [chassis-ui/icons](https://github.com/chassis-ui/icons) | `@chassis-ui/icons` |
</CxTable>

## AI agents

Chassis MCP is not a package of the design system. It is a server that gives an AI agent the skills to work with the packages: to build a design in Figma from the library, to turn a design into Chassis CSS markup, and to add a brand. Its repository is [chassis-ui/mcp](https://github.com/chassis-ui/mcp).

## Introduction

Chassis is developed in the open, in the [chassis-ui organization](https://github.com/chassis-ui) on GitHub. This page covers where to follow the work, where to report a problem and how to contribute.

## Follow the project

The [blog](/blog/) has the announcements and the articles about Chassis. Each package lists its changes in the changelog of its repository and in its GitHub releases.

## Report a problem

Each package has its own issue tracker. Open the issue in the repository of the package that the problem is in; the [Introduction]([[docsref:/getting-started/introduction#the-packages]]) lists the repository of each.

A problem with this website or with these guides goes to [chassis-ui/website](https://github.com/chassis-ui/website/issues), and a problem with the MCP server or a skill to [chassis-ui/mcp](https://github.com/chassis-ui/mcp/issues).

## Report a vulnerability

Do not report a security vulnerability in a public issue. Each repository has a security policy, in its **Security** tab on GitHub, that says how to report one privately.

## Contribute

A small fix is welcome as a pull request. For anything larger, open an issue first, so that the change can be agreed on before the work. [Contribute](/about/#contribute) on the About page covers the rest, and each repository has a contributing guide of its own.

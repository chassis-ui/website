## Read the documentation of each project

Each project has its own documentation:

- [Chassis CSS](/css/): installation, core concepts, customization, layout, forms, components and utilities.
- [Chassis Tokens](/tokens/): the token sets, the build, and how to use the tokens on the web, iOS and Android.
- [Chassis Icons](/icons/): the icon set, how to use it as a sprite, a font or SVG files, and how to build your own icon library.
- [Chassis Assets](/assets/): the asset types, the build, and how to use the assets on the web, iOS and Android.
- [Chassis Figma](/figma/): how to set up the Figma libraries, work with themes, and the components of the library.
- Chassis React: its documentation is not on this site yet. The [repository on GitHub](https://github.com/chassis-ui/react) covers installation and usage.

## Follow the project

The [blog](/blog/) has announcements and articles about Chassis. The source of every project is in the [chassis-ui organization](https://github.com/chassis-ui) on GitHub.

## Report a problem

Each project has its own issue tracker on GitHub. Open an issue in the repository of the project that the problem is in:

<CxTable>
| Project | Issues |
| --- | --- |
| Chassis Tokens | [chassis-ui/tokens](https://github.com/chassis-ui/tokens/issues) |
| Chassis CSS | [chassis-ui/css](https://github.com/chassis-ui/css/issues) |
| Chassis Icons | [chassis-ui/icons](https://github.com/chassis-ui/icons/issues) |
| Chassis Assets | [chassis-ui/assets](https://github.com/chassis-ui/assets/issues) |
| Chassis Figma | [chassis-ui/figma](https://github.com/chassis-ui/figma/issues) |
| Chassis React | [chassis-ui/react](https://github.com/chassis-ui/react/issues) |
| This website and these guides | [chassis-ui/website](https://github.com/chassis-ui/website/issues) |
</CxTable>

Do not report a security vulnerability in a public issue. If the repository has a security policy, follow it to report the vulnerability privately.

To contribute a change, read [Contribute](/about/#contribute) on the About page. For anything larger than a small fix, open an issue first.

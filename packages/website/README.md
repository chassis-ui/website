# chassis-website (Astro app)

> The Astro application that builds [chassis-ui.com](https://chassis-ui.com).

This is a private package inside the [`chassis-ui/website`](https://github.com/chassis-ui/website) monorepo. It uses [`@chassis-ui/docs`](../docs/README.md) for its layouts and components, `@chassis-ui/css`, `@chassis-ui/website-tokens` and `@chassis-ui/website-icons` from npm, and the assets of a pinned release of chassis-ui/website-assets, unpacked into `vendor/assets`.

Run its commands from the root of the repository. For setup and commands, see [CONTRIBUTING.md](../../CONTRIBUTING.md#setup).

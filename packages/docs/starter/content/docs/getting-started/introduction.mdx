## Overview

This site is built on [`@chassis-ui/docs`](https://www.npmjs.com/package/@chassis-ui/docs). It has the parts that every Chassis documentation site needs, and nothing else.

## What to change

1. Set the keys of `config.yml`. Point `sourceDir` at the code that the site documents, and delete the `source` directory.
2. Replace the pages in `content/docs` and their entries in `data/sidebar.yml`.
3. Copy the logo, favicons and social image from the docs build of `chassis-assets` into `public/static/`. See `src/libs/static.ts`.

The [shortcodes page]([[docsref:/getting-started/shortcodes]]) shows every shortcode that the package provides.
